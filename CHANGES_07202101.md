## Bug fixes

### 1. `tests/agent/hf_local/test_session_recorder.py` — NoOp assertion against shared `tmp_path`

**Symptom:** `TestNoOpRecorder::test_is_noop_when_disabled` failed with
`AssertionError: assert not True` — i.e. `tmp_path` was not empty even though
`NoOpRecorder` never writes anything.

**Root cause:** The project-wide `_hermetic_environment` autouse fixture
(defined in `tests/conftest.py`) always creates a `hermes_test/` directory
tree inside `tmp_path` for every test:

```python
fake_hermes_home = tmp_path / "hermes_test"
fake_hermes_home.mkdir()
(fake_hermes_home / "sessions").mkdir()
...
```

So `any(tmp_path.iterdir())` is always `True`, regardless of what the test
does.

**Fix:** Changed the assertion from a blanket "tmp_path is empty" check to
the specific invariant that actually matters — `logs/` and `profiling/`
directories (the only paths `ActiveRecorder` writes to) must not exist:

```python
# before
assert not any(tmp_path.iterdir())

# after
assert not (tmp_path / "logs").exists()
assert not (tmp_path / "profiling").exists()
```

### 2. `tests/agent/hf_local/test_config_gate.py` — Registry clear poisoned subsequent tests

**Symptom:** When the four new test files were run together in one `pytest`
invocation, nine transport-registry tests failed with `None is not None`.
All nine passed in isolation.

**Root cause:** `TestConfigGateImports::test_transport_registered_in_registry`
manually cleared the module-level transport registry and reset the discovery
flag:

```python
import agent.transports as tr
tr._discovered = False
tr._REGISTRY.clear()
```

Python's module import cache means that `import agent.transports.hf_local`
inside `_discover_transports()` is a no-op after the first import — the
module body (including its `register_transport(...)` call) only runs once.
After the clear, re-discovery silently produced an empty registry, and all
subsequent `get_transport("hf_local")` calls in later test files returned
`None`.

**Fix:** Removed the registry manipulation entirely. The test now just calls
`get_transport("hf_local")` directly, which is sufficient to verify that the
transport is registered and discoverable through normal initialization:

```python
def test_transport_registered_in_registry(self):
    from agent.transports import get_transport
    t = get_transport("hf_local")
    assert t is not None
    assert t.api_mode == "hf_local"
```

### 3. `agent/interp/kv_probe.py` — Shape mismatch in decode-window attention matmul

**Symptom:** `TestComputeProbeRows::test_decode_row_count` and
`test_decode_seq_pos_windows` failed with:

```
RuntimeError: mat1 and mat2 shapes cannot be multiplied (3x6 and 3x8)
```

**Root cause:** In the decode-phase windowing loop, the code sliced both the
attention weight matrix and the value matrix to the current window, then
tried to multiply them:

```python
V_k = v_states[0, kv_head_idx, win_start:win_end, :]   # (win_len, head_dim)
A_q = attn_weights[0, q, win_start:win_end, :win_end]  # (win_len, win_end)
c_q_seq = A_q @ V_k                                    # FAIL: (win_len, win_end) @ (win_len, head_dim)
```

In a causally-masked model, query position `i` attends over **all** prior
key positions `[0..i]`, not just positions within the current window.
`A_q` has shape `(win_len, full_seq_len)` and must be multiplied against the
**full** key sequence `V_k_full` of shape `(full_seq_len, head_dim)`.
Slicing `V_k` to the window length made the inner dimensions incompatible
for any window other than the first.

**Fix:** Separated full-sequence and windowed value slices. The attention
matmul (`output_contribution` mode) now uses the full key sequence; the
windowed slice is only used for the `value_projection` mode where no
attention weights are involved:

```python
# full key sequence — needed for causal attention matmul
V_k_full = v_states[0, kv_head_idx, :, :]
# window slice — used only for value_projection (unweighted mean)
V_k_win  = v_states[0, kv_head_idx, win_start:win_end, :]

# output_contribution path:
A_q = attn_weights[0, q, win_start:win_end, :]   # (win_len, seq_len)
c_q_seq = A_q @ V_k_full                          # (win_len, head_dim) ✓

# value_projection path:
c_q = V_k_win.mean(dim=0)   # (head_dim,)
```
